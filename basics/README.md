# Basics

- 0-current_working_directory: Prints the absolute path of the current working directory.
- 1-listit: Lists the contents of the current working directory.
- 2-bring_me_home: Changes the working directory to the user's home directory using cd ~.
- 3-listfiles: Displays the contents of the current working directory in long format using ls -l.
- 4-listmorefiles: Displays all directory contents, including hidden files, in long format using ls -la.
- 5-listfilesdigitonly: Lists all directory contents in long format, including hidden files, with numeric user and group IDs using ls -lan.
- 6-firstdirectory: Creates the my_first_directory directory inside /tmp.
- 7-movethatfile: Moves the betty file from /tmp to /tmp/my_first_directory.
- 8-firstdelete: Deletes the betty file from /tmp/my_first_directory.
- 9-firstdirdeletion: Removes the my_first_directory directory from /tmp using rm -r.
- 10-back: Changes the working directory to the previous directory using cd -.
